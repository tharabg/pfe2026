# 📜 Code of Conduct

## Notre Engagement

En tant que contributeurs et mainteneurs du projet **TopNet OCR**, nous nous engageons à créer et maintenir un environnement accueillant, inclusif et respectueux pour tous, indépendamment de:

- L'âge, le handicap, l'ethnicité
- L'identité de genre et l'expression de genre
- Le niveau d'expérience
- La nationalité, l'apparence personnelle
- La religion, l'orientation sexuelle

---

## Nos Standards

### ✅ Comportements acceptés

- Utiliser un langage accueillant et inclusif
- Être respectueux des points de vue et expériences différents
- Accepter les critiques constructives avec grâce
- Apprécier les contributions au projet
- Se concentrer sur ce qui est le mieux pour la communauté

### ❌ Comportements inacceptables

- Langage ou images sexualisés
- Attaques personnelles ou insultes
- Trolling, commentaires déraisonnables
- Harcèlement public ou privé
- Publication d'informations privées sans consentement
- Autre conduite déraisonnable

---

## Nos Responsabilités

Les mainteneurs du projet sont responsables de:

1. **Clarifier** les standards de comportement acceptable
2. **Prendre des mesures** appropriées et justes en cas de violation
3. **Supprimer** les contributions inappropriées, commentaires, commits, issues qui ne respectent pas ce code de conduite

---

## Signaler une violation

Violations de ce code de conduite peuvent être reportées:

📧 **Email**: [email protected]  
🐛 **GitHub Issue**: [Créer une issue privée](https://github.com/TOPNET/topnet-ocr/issues)  
💬 **Discussion**: Via channel discussions GitHub

### Traitement des rapports

1. Confirmation de réception sous 48h
2. Investigation impartiale
3. Actions appropriées (avertissement, suspension, ban)
4. Notification du résultat

---

## Confidentialité

Tous les rapports seront traités avec confidentialité. Les détails personnels du rapporteur ne seront pas publiés sans consentement.

---

## Cumul avec les politiques

Ce code de conduite s'ajoute à toute politique applicable sur GitHub, TOPNET, ou dans votre juridiction.

---

## Remerciements

Ce code de conduite est adapté du [Contributor Covenant](https://www.contributor-covenant.org/), version 2.0.
